### 修复 1：hardware_planner 接入运行路径（发现：接了但没用）

**发现**：`plan_allocation` 仅被 scripts/model_smoke.py 调用，模型启动路径不
走硬件规划（翻译启动用 config.local_gpu_layers，审核/rerank/embed 用 registry
模板值；review_server 构建命令硬编码 gpu_layers=-1）。

**修复**：
- `hanhua/core/local_model.py`：新增 `_planned_gpu_layers(app_dir, kind)`，
  两处 `requested_layers == -1` 时用规划结论覆盖（4~6GB 档 1.8B 翻译 CPU、
  4B 审核拿唯一 GPU 名额防 OOM；≥8GB 档双 GPU 全层；无 GPU 全 CPU）。
  探测失败返回 None → 回退用户配置 + 运行时回退链（999→0→999）兜底。
- `hanhua/core/review_server.py`：ensure_running 用规划覆盖 ctx 与 gpu_layers
  （显存紧张自动降 4096），失败回退模板。
- 新增 `tests/test_hardware_planner.py`（5 个打通测试，含探测失败路径）。

**验证**：test_hardware_planner + test_local_model 19 passed。
