# 闭环记录模板规范（记录升级标准，2026-08-12）

> 背景：用户实证「记录不能只是形式的记录，本质还是老的模式」——
> 「翻译评价：已产出译文 / 需要优化：否」是空功能；闭环要求全面、
> 记录必须确实有用、有严格标准、根据记录能提升。本规范定义每款
> 游戏三份文档的**实质内容标准**，并随大闭环沉淀持续升级。

## 0 原则

1. **记录驱动提升**：每份记录必须包含「发现 → 处置 → 沉淀」闭环。
   只描述现象不给出处置和沉淀的段落，视为不合格。
2. **严格标准**：所有结论必须给出判定依据（为什么算合格/不合格），
   不能只写「正常」「通过」。
3. **可追溯**：每个结论指向证据（text 记录/审核报告/测试日志/文件
   :行号）。
4. **实质字段**：翻译评价/需要优化等字段必须是语义审核（reviewer）
   的实质输出，不是形式占位。

## 1 analysis/analysis-final.md（分析报告）

必须包含：
1. **失败收敛过程**：每轮失败数 + 失败文本 + 处置（修复/观察项），
   注明确定性（跨轮重跑一致 = 确定性）
2. **失败分类**：每条失败按「判定误杀 / 判定漏豁免 / 模型能力边界 /
   模型波动」四类归档，每类给出判断证据
3. **语义审核结果**（新标准）：引用 review/review-report.md——
   不合格条数、问题分布（术语/语境/专名/语义/风格）、代表性案例
   （如 Resume→简历）、处置（重译/接受/沉淀术语）
4. **正确性复核**：本轮修复的直接证据（run2 中该条由失败转成功）、
   防过宽对照（不掩盖真半翻译）
5. **结论**：已闭环 / 观察项清单（模型边界原文保真不修复的，写明
   升级后重跑验证条件）

不合格形式：只抄写失败清单没有分类；审核不合格项无处置。

## 2 fix record/fix-record.md（修复记录）

必须包含：
1. **触发**：哪款游戏哪条失败暴露（原文/译文/来源），为什么这是
   通用形态不是单游戏特例
2. **形态特征**：可判定的形式化描述（正则/结构/语义特征），
   「真实 X 不以 Y 形态出现」的防误伤边界
3. **实现**：文件:行号 + 接入点（哪一层：识别跳过/翻译/质量门/审核）
4. **判定依据**：为什么这是正确行为（与既有规则对齐的引用）
5. **防过宽**：对照测试（不掩盖真半翻译的反例）
6. **实证**：修复后该游戏重跑结果（失败 → 0 或 → 观察项）
7. **观察项**：不修复的问题记录判断依据（模型边界/波动），写明
   重跑验证条件

不合格形式：只写「修复了 X」没有形态描述；无对照测试。

## 3 final report/final-report.md（最终报告）

必须包含：
1. **概览表**：闭环轮次、翻译条目、失败数（含观察项数）、写回状态
2. **流程结果**：识别/翻译/写回/清理四步的真实数据
3. **质量结论**：
   - 失败分类汇总（判定误杀 0 / 模型边界 N）
   - 语义审核结论（新标准）：审核条数、不合格数、问题分布、处置
   - 术语沉淀（新标准）：本轮审核沉淀的词对数（Resume→继续 等），
     说明后续游戏如何受益
4. **知识库沉淀**：本轮新增 F# 修复、术语词对、观察项——明确
   「后续游戏如何用上」
5. **状态**：✅ 已闭环（写明依据）

不合格形式：语义审核不合格项无处置；沉淀描述
空洞（无词对/无规则）。

## 4 知识库沉淀标准（每轮闭环必须产生）

| 沉淀类型 | 来源 | 去向 | 生效方式 |
|---|---|---|---|
| 判定规则 F# | 失败分类（判定误杀/漏豁免） | batch_translator/quality/placeholders | 代码 + 测试，后续游戏自动生效 |
| 术语词对 | 语义审核（Resume→继续） | glossary.db「审核术语」 | 翻译 prompt 注入，按词对约束 |
| 失败案例 | 失败模式聚合 | knowledge.db | 后续同模式命中提示方案 |
| 观察项 | 模型边界/波动 | fix record 观察项 | 模型升级后重跑验证清单 |

## 5 记录质量检查（文档写完自检）

- [ ] analysis：失败按四类归档且证据充分
- [ ] analysis：语义审核不合格项逐条有处置
- [ ] fix record：每条修复有形态描述 + 防过宽对照 + 实证
- [ ] final report：实机测试逐项结果（含证据路径）
- [ ] final report：术语沉淀词对数（>0 或说明无术语问题）
- [ ] 知识库/术语库实际写入（不是文档里说说）
