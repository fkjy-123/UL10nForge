## 阶段 B：核心修复（8/9/10）

### #8 译文保存两缺陷
- 缺陷 1：相同文本不能保存（必须变化才写入）→ 改为相同文本也直接保存
- 缺陷 2：编辑后 ~2 秒变回原文本 → 编辑状态被 store 刷新/失焦重置覆盖；修复：正在编辑的条目不参与刷新，保存成功后清编辑态
- 验证：相同文本保存成功（状态提示）；编辑后等待 >2 秒文本不回退

### #9 手动修改真正保存/写回 + 失败文本自处理
- 手动修正 → store（含相同文本）→ write_all 写回链路端到端验证
- 失败/跳过文本在审校界面可处理：手动改、重新翻译、确认跳过
- 验证：改一条 → 发布 → 副本确认生效；failed/blocked 条目可操作

### #10 翻译提示词 Style/Personalization
- translator.py/prompts.py 系统提示词加入：游戏本地化专家角色 + 10 条行为边界（用户提供文本精简版）
- play/resume 等语境词按游戏语境译（不再机械翻「播放/简历」）
- 支持按游戏档案（profile）自定义提示词/风格要求
- 验证：单测断言提示词包含角色与边界条款；hickory 重译 play→按语境

## 阶段 F：字体纵深（12/1）

### #12 minato 口口缺字逐码点全链验证
按字体问题文档 34 节原则实现「字体完整性验证器」：
1. 提取需求集（译文实际码点）
2. 对每个码点验证：bundle charset → 替换后字体 CharacterTable → GlyphTable → Atlas rect/尺寸 → Fallback 链
3. 输出 Font Coverage Report（Total/Supported/Missing + 缺失码点列表）
4. minato 实测：诊断「中文+口混现」的具体缺失码点 → 按缺失原因修复（bundle 缺字符/特殊字符/引号/fallback）
5. 缺字符自动补字（无法由当前字体提供 → 诚实报告 + 建议）
- 检查计划：minato 副本全码点验证 Missing=0 或逐条人工确认；hickory 回归不破坏

### #1 字体防复发
- install_static_fonts 完成后追加自检：图集引用同文件解析 ✓ / AtlasW/H 与纹理一致 ✓ / 无关纹理未被修改 ✓ / mode=0 ✓
- 自检失败 → 消费者标记未覆盖（不假 PASS）
- 回归测试已含 3 个（跨文件重号/mode/尺寸字段）；再加「验证器」测试
- 验证：hickory 重发布仍 PASS；自检代码存在；构造坏副本 → 自检拦截
