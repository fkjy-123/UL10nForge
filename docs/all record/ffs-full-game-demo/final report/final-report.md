## 知识库沉淀

- **F23 方向语义检查**（ffs run3 主产物）：输入绑定语境（含设备词
  stick/button/hat/pov/switch/trigger/shoulder/wheel/throttle/dial/
  shifter/paddle/pedal/lever/knob/rotary 或键位后缀 `:xxx`）+ 原文含
  方向词 + 译文含中文 → 译文必须含对应方向字（左/右/上/下），缺失
  即失败——兜住 1.8B 对方向盘 HUD 方向组合的语义失控
- **术语表污染事故修复**（§0.14 + fix record 详录）：沉淀端首词
  提取禁止（形态 2 source 用整个短原文 ≤5 词）+ 方向/设备单字对
  永不入库 + 20 条污染词对清洗——防再生三端
- **IL2CPP 交叉验证证据持久化**：`il2cpp_cross_check` profile 键
  存 route/tool/agreement，resume 时恢复轻量 report——修 resume
  写回闸门「缺少交叉验证证据」问题
- **恢复流程二次实证**：写回成功后库被清理 → scan_all 重建 + 新
  质量门验证导入（通过=import translated，失败=留 pending）→ 补翻
