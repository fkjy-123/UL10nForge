## 修复记录（F11 四修 + F12 占位符破碎）

### F11a 富文本标签透明化（quality.py `_label_context_match`）

- **标签内 token 豁免**：`<size=120%>` 的 size / `</size>` 是标签属性/标签名，
  标记语言不是可翻译文本——判据：token 前最近 `<` 到 token 之间无 `>`（未
  闭合标签段内）。`<b>Weapon:</b>` 的 Weapon 在标签内容里（前有 `>`）→
  照常适用词对（漏翻仍拦截）
- **句首判定跳过标签**：`<b>Full version on Steam</b>` 的 Full 语义上是句子
  首词（左邻 `>` 是标签结束符，原判定误认为句中 UI 词）——左邻扫描遇 `>`
  回跳最近 `<`，标签是装饰层不影响语境判定

### F11b 文件名段豁免（quality.py `_in_filename_segment`）

- `player-diagnostics.txt` 的 Player 是文件名标识符不是语义文本——token
  所在连续段（[A-Za-z0-9_.-]+）含 `-`/`_` 且以 `.ext` 结尾 → 词对不适用。
  防误伤：`fight-or-flight` 不以 .ext 结尾不受影响

### F11c 方向词单字对不强制（quality.py 词对过滤）

- left/right/up/down 做全局强制必然误杀自然副词（「请在右侧购买工厂」被
  (RIGHT→对) 误杀——force-reboot 沉淀，正是「方向/设备词单字对是污染源」
  教训的落实缺口）。方向语义由 `_input_binding_context` 专用检查负责
  （输入绑定语境强制查方向字），词对层不做全局强制

### F11d 数据修正（agent_memory.db）

- RIGHT→对（force-reboot 沉淀）、full→完整的 降级 retired——单字方向词对
  与高频形容词对是污染源，保留记录可人工复核

### F12 占位符破碎检查（placeholders.py `validate_translation`）

- **实证（row207/644/684/714 共 4 条漏网）**：模型把 {health} 本地化成中文
  变量名（{伤害}/{速度惩罚}/{产生惩罚}）并**在尾部重复堆叠原文占位符**
  （{health}{damage}...）——brace 提取只匹配 ASCII，中文花括号段逃过 →
  Counter 恰好相等 → 通过质量门 → 写回游戏内是乱码
- **修复**：译文 {..} 花括号段必须都是原文占位符（非 ASCII 段 extra——
  变量名本地化破坏运行时替换）；原文有占位符时译文孤立花括号（「健康}
  HP」的 }）判 `<lone-brace>` 破碎
- 防误伤：原文无占位符时对话文本花括号（「他说这是{}」）不拦截；
  正常保留（HP {health}→生命值 {health}）不受影响
