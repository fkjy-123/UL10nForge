## 2 游戏结构专项：DELTATRAVELER 对话标记

Undertale 系对话脚本的三类标记是本游戏命脉，也是模型系统性丢失对象：

1. **行首 `* ` 对话符**——每行一个（`* You found the <color=#00FF00FF>[MOSS]</color>!`），
   模型常整段丢弃或移位（`* 只有无畏的人才能继续前进。` 移位成
   `只有无畏的人才能继续前进。* `）
2. **`^NN` 计时码**——形式多样：`,^05` 逗号后、`.^05` 句点后、`…^05`、
   行首 `^05* ` 接对话符、`?` 后、`)^05` 括号后
3. **字面 `\n`**——C# 转义（两字符）而非真换行分隔对话行（约 1400 条）

模型对这三类的行为：整段丢弃 `* ` 对话符（最常见）、丢计时码、字面
`\n` 行合并。F13 三修（见 fix record）后全部可拦截。

对话脚本文本是叙事自由语义——(PLACE→地点) 杀「那个地方」、(NAME→名称)
杀「你叫什么名字？」、(Time→时间) 杀「时光/时机」、(Play→播放) 杀
「玩 UNO」、(SHOOT→射击) 杀感叹「哦，天哪」全部实证。F13a 判据
（`* ` 行首 + 括号/大写、`^NN` 计时码、全大写喊话 ≥3 词 + 句子标点）
识别对话脚本后豁免单 token 普通词词对；keep 型（target==source 保留
映射）与多词短语词对（FULL SCREEN→全屏显示）仍强制。
