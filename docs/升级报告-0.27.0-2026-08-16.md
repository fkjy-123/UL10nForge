# UL10nForge 版本升级报告（2026-08-16）

## 版本定位

本版本（0.27.0）为**识别能力全面升级 + 工具链能力集成**版本。基于
地毯式大排查（155 游戏）的真实闭环，修复 22 项识别缺陷、集成 4 项
外部工具能力、新增智能上下文、自动拦截自带中文游戏。

## 一、识别机制升级（F33-F54，22 项）

### 识别率质变

- **之前**：识别率约 75-80 分——典型游戏漏 20-25%（78-hour-rain 漏
  78% 文本、adapt 漏 74%、shellcore 漏 67%）；且分母由识别链自产自销
  （不可验证）
- **现在**：155 游戏**零未解释缺口**——每个游戏人工对照（census 字节
  级扫描 + 提取池差集 + 缺口逐条归因），识别率约 90-93 分（剩余为
  已知观察项 <2% + 加密/视频不可达内容）；分母首次有独立验证

### 智能上下文（用户指令 2026-08-16）

按游戏文本统计实时计算 ctx：单条硬约束（最长原文+输出上限+开销）+
批量需求 × 安全余量，夹 [2048, 16384]。切换批量条数不影响单条兜底。
实测：drova 长文本 8699 → 小游戏 2048（不冗余）。

## 二、工具链能力集成（四任务）

| 能力 | 集成方式 | 管线作用 |
|---|---|---|
| **UnityCN 加密解密**（AssetStudio/UnityPy 算法） | `unitycn_decrypt.py`：key 暴力探测（bundle+metadata 双源）+ 全局解密接入；extractor 自动探测，无 key 标记 blocked | 加密 bundle 从"不可见"→自动解密提取 |
| **写回校验修复**（UABEA patchcrc 等价） | `bundle_crc.py`：UnityFS header hash(MD5)/crc(CRC32) 重算+修复；writer 写回验证记录校验字段状态 | 写回产物对严格校验路径也有效 |
| **IL2CPP metadata 写回**（patcher/MetaDataStringEditor） | `il2cpp_writeback.py`：译文追加新数据区+重建索引表（explicit/implicit 双模式）——任意变长无截断 | IL2CPP 游戏写回能力（11 个真实游戏验证） |
| **字体合并与裁剪**（Font-Merger + FilterRepeatCharacter） | `font/font_merge.py`：CFF 按需求集转 glyf + fallback 补缺 + 字符集去重裁剪 | 缺字场景自动补全（真实 OTF 6.5 万字形合并验证） |

依赖：pycryptodome、fontTools（已装入离线 runtime）。
全量回归 2393 passed，零冲突。
