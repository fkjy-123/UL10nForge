# 工具能力移植计划（2026-08-16，四任务）

> 用户指令：把四个高价值工具的能力完全移植到本工具架构管线，完美解密
> 提取自动化算法与逻辑，无冲突、无 bug，写好计划再执行，执行后复查。

## 源码位置

`tools/sc/`：AssetStudio-0.16.47（UnityCN 参考）、UABEA-8（CRC 参考）、
MetaDataStringEditor-0.0（IL2CPP 写回参考）、Warcraft-Font-Merger-1.1.0
（字体合并）、il2cpp-stringliteral-patcher-master（IL2CPP 写回主参考）
+ FilterRepeatCharacter（CSDN 文章——被墙未读到，核心=字符集去重，
按需求集自实现，与 Font-Merger 的 TrimGlyph 同思路）。

## 关键发现（勘察结论）

1. **UnityCN 解密**：UnityPy 已含 Razmoth 同源 Python 实现
   （ArchiveStorageManager：AES-ECB+XOR 双层 + brute_force_key +
   ArchiveStorageDecryptor 流式解密）——**无需移植 C#，直接集成**
   缺依赖：pycryptodome（AES）
2. **UABEA patchcrc**：CRC 在编译 DLL（无源码）——CRC32 标准算法
   自实现；先验证 UnityPy 写回是否已处理 bundle CRC
3. **IL2CPP 写回**：il2cpp-stringliteral-patcher（Python 80 行核心：
   追加新数据区 + 重建 lookup_table + 更新数据偏移）——**直接移植**
4. **字体合并**：Warcraft-Font-Merger（otfcc otd 格式操作——合并=
   cmap/glyf 并集 + TrimGlyph 裁剪）——用 fontTools 重新实现（runtime
   无 fontTools，需安装）；FilterRepeatCharacter = 需求集字符去重

## 任务顺序

### 任务 1：UnityCN 加密 bundle 解密提取
- 依赖安装：pycryptodome
- 新模块 `hanhua/core/unity/unitycn_decrypt.py`：
  - `detect`（魔数已有）+ `brute_force_key`（文件内 `\w{16}` +
    global-metadata.dat 双源探测）+ `decrypt_bundle`（AES-ECB 解
    头向量 + ArchiveStorageDecryptor 流式解密块）
- 集成 `unity/extractor.py`：find_asset_files 对 unitycn_encrypted
  文件 → 自动探测 key → 解密为内存 buffer → 正常 UnityPy 解析
- 写回限制：UnityPy encrypt 未实现——解密态写回（标记原加密，
  写回保持解密格式，游戏读取兼容性标注观察项）
- 测试：合成加密 bundle（用实现 encrypt 验证解密往返——自实现
  encrypt 仅测试用）+ 真实文件不可得则用结构断言

### 任务 2：写回校验修复（patchcrc 等效）
- 验证 UnityPy `save()` 后 UnityFS header hash 是否有效（读回检查）
- 若无效：新模块 `hanhua/core/unity/bundle_crc.py`——UnityFS
  header 结构解析 + CRC32 重算 + 修复
- 集成 `writer.py`：容器写回后校验/修复
- 测试：合成 UnityFS bundle 修改后修复验证

### 任务 3：IL2CPP metadata 写回
- 依赖：无新增
- 新模块 `hanhua/core/unity/il2cpp_writeback.py`（移植 patcher）：
  - 提取 lookup_table（length+index 对）与 stringliterals
  - 更新：译文 → 追加新数据区（文件末尾）→ 重建索引表 →
    更新 STRINGLITERAL_DATA_DEFINITION 偏移
- 集成：il2cpp 提取（现有）→ 写回路径（writer 支持 metadata）
- 注意：写回后 game assembly 读取一致性（免实测——结构级验证：
  索引表/偏移/容量断言）
- 测试：合成 metadata 结构往返 + 真实文件（8morelives 无 IL2CPP——
  用提取的 metadata 结构验证）

### 任务 4：字体合并 + 裁剪
- 依赖安装：fontTools
- 新模块 `hanhua/core/font/font_merge.py`：
  - `merge_fonts(primary, fallback, needed_chars)`：cmap/glyf 并集
    合并 + TrimGlyph 裁剪（只保留 needed_chars + 引用字形）
  - `collect_needed_chars(entries)`：译文+原文字符集去重
    （FilterRepeatCharacter 逻辑）
- 集成 font 管线：legacy 字体缺字（如希伯来文/▶）→ 自动合并
  补全字体 → 发布
- 测试：合成 TTF 合并/裁剪验证（字符集断言）
